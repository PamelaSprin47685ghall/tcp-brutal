# 下行 1×256 SC-LDPC：n 范围、BP 门限、256 份有限长修正

2026-11-11，master 66ecd19。Monte Carlo 扫描已停；改用确定性 BEC 密度演化（DE），保留锚点见 sclc-down.csv。

## 1. 可构造范围

图（sclc_build_graph）：L=8 块，每块 n 个 payload、m 个 parity 变量和 m 个 check；payload 度 dv=5（n≤m）/4（n>m）；每 check 另有 1 条自有 parity 边，j>0 再收 1 条前块边。四平面计数器表示 0..15 ⇒ check 度 ≤15。

n≤m：每 check 每源块至多 1 条 payload 边，度 ≤5+2=7。

n>m：q=⌊n/m⌋、r=n mod m，每 check 每源块 q 或 q+1 条边，度 ≤4(q+1)+2（r=0 时 4q+2）；≤15 ⇒ r>0 时 q≤2，r=0 时 q≤3，合并 n≤3m ⇒ n≤192。

n+m=256 ⇒ n_min=1、n_max=192；--range 实测构造器接受 1..192、拒绝 193..255。线上策略再限到 64..178 六点。

仅为档位而设：down_split() 六点白名单（tbt_fec.c:2406）；wire_of_cfg() 的 rate_ppm∈[25%,70%]、down_split()、rate_index_for_shape()≠0xff。block=256/L=8/groups=1/shares=256 是 codec 形状约束；rate_ppm·shares/1e6=n 是一致性检查。sclc_new() 只查 n,m>0、n+m=256、s=8192、w=256、d=0、k 与 n/m 一致。

## 3. 256 份有限长修正

实测相关擦除：share s 擦掉缓冲区变量 8s..8s+7；n=64/128 时 8|n，这 8 个变量全在同一耦合块（只影响该块 dv 个 supernode），n=76/102/151/178 时可能跨两块；不是每块一个。故独立符号是 256 份而非 2048 bit。

DE 边际递推不变（同 share 双边概率 ≈C(dv,2)/n=5.6%..15.6%），但擦除计数方差 ×8，N_eff=256，瀑布宽度 ×√8。

Amraoui：P_fail≈Q(√N(ε*−ε)/α)，N=256，α=0.60（n=128 p=0.35/0.40→0.573/0.578；n=151 p=0.25/0.30→0.651/0.633；n=178 p=0.15→0.562；1–2 次失败点 0.725/0.900 弃用）。

δ(P)=αQ⁻¹(P)/16：P=1e-2/1e-3/1e-4 → 0.087/0.116/0.140（22.3/29.7/35.7 份）。20% 余量=51.2 份，覆盖 1e-4 需 Δ≤15.5。

故 α=0.60 下六档边界均偏保守 0.001..0.017（0.1..4.4 份），50% 档几乎正中；α>0.60 时 40/50% 档转为偏乐观。25% 无锚点，是外推。

方差：M 块测 1e-4 阈值时 σ_p≈0.95/√(M/10⁴) pp（10⁴→0.95pp，10⁵→0.30pp）。图实例方差不在 DE 内：n=128 p=0.35 的 5 个 nonce 为 0.3%..1.5%（各 1000 块），大于二项噪声。

解析可得：ε*(n)、Δ(n)、δ(P) 形式、σ(M)；只能实测：α 精确值、块内 8 连擦的二阶修正、单图实例方差、真实 1e-4 点。

## 4. 保留锚点与反常

iid n=128 p=0.30/0.35/0.40 → 1/1000、6/1000、134/1000；n=151 p=0.20/0.25/0.30 → 2/1000、3/1000、59/1000；n=178 p=0.15 → 4/5100。

0 ms 抢跑：n=128 p=0.30 首次可解中位 144（n+8=136），首试失败 100%，9.5 次尝试/块；n=178 p=0.10 中位 191（186），6.4 次。128 batch 同 mask 同图：50 个失败块中 0 个 share 被部分写入，全部 batch 同败；块失败=一次 peeling，不是 8192 码字独立失败。

DE 小固定点使“x→0”门限低估（n=128 得 0.187 vs 跳变 0.440；n=64 的误差底到 0.016 才跳变），必须取大分支跳变点。
