## 3. 已知限制

- SC-LDPC 单流：并发第二流返回 `-EOPNOTSUPP`；多流需 `mode=grouped` RLNC + `fec_groups_per_flow=16`；顺序 SC-LDPC 可复用，但需前流释放。
- 下行自适应固定 rate50：binary 1×256/L8 只有 128/128；只有上行 GF(16) 8×32/L16 沿阶梯切。
- 内核最低 6.1：5.15 缺 `pde_data` 且源码 `#error`；矩阵 5.15 两格 FAIL 属设计边界。
- crypto key 边界：tunnel 级 key 跨 session/stream churn；模块 reload 或 tunnel delete+re-add 会清掉它。near 单端重载/重建会生成新 key，far 仍钉旧 key 时按 `crypto key changed` 拒绝；两端同载/重建，或显式 `crypto_key=`。
- 6 条 SYN 卡住：join `up=250/256`、near `replacing=6`/far `empty=6`，SYN-SENT/SYN-RECV；属路径/NAT 丢 SYN，`rx_proto/rx_errs=0`，记录不判产品失败。
- 流 teardown 慢（发布风险）：G1-r4/G3 显示 1 GiB 流结束后 >2 min `streams_active=1`；G3/G4 前需确认 `streams_active=0` 或 fresh reload。
