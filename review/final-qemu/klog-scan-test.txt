klog scanner fix - verification
================================

Changed file: adversarial/run.sh
Diff: review/final-qemu/klog-scan-fix.diff

The old scan grepped the whole console for
  BUG:|Oops|general protection fault|INFO: task .* blocked|deprecated workqueue
so the guest's own PASS line
  ADV_RESULT init.dmesg PASS no WARNING/BUG/Oops/INFO: task in the guest log
matched on the literal word "Oops".

The new klog_count() first skips harness output
  ^ADV_ ^PHASE_ ^TBT_ ^NEARX_ ^FAR_ ^CONC_ ^REPRO_ ^PARTIAL_WROTE ^burst: ^== ^#
then accepts only timestamped kernel lines or lines that start with a kernel
marker, and counts these patterns:
  WARNING: BUG: Oops general protection fault Call Trace:
  INFO: task .* blocked refcount_t: KASAN UBSAN deprecated workqueue

Measurements on the archived console of the first (pre-fix) run,
review/final-qemu/adversarial-console-final.log:

  old_grep = 1     (the ADV_RESULT init.dmesg PASS self-match)
  new_scan = 0

All other consoles of that run (public control resource slab replay rmmod
flush catconfig cfg_mix param port near far stall, crash) also scan 0.

Negative test on a temporary copy (not committed, deleted afterwards):

  append '[    1.000000] WARNING: synthetic negative test'
  append 'ADV_RESULT fake PASS no WARNING/BUG/Oops/INFO: task in the guest log'
  -> klog_count = 1        (real timestamped WARNING counted, harness line skipped)

  append 'Call Trace:'
  -> klog_count = 2        (bare kernel continuation line counted)

  append '[    2.000000] BUG: unable to handle page fault for address 0000000000000000'
  -> klog_count = 3        (timestamped BUG counted)
